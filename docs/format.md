# LuckyWiki 마크다운 규격

옵시디언에서 그대로 열리는 마크다운이다. 조립·파싱 코드는 `server/src/notes/format.ts` 한 곳에 있다.

```markdown
---
title: "프로세스와 스레드 차이"
slug: 프로세스와-스레드-차이
created: 2026-09-23
updated: 2026-09-23
tags: [os]
model: exaone3.5:2.4b
question: "프로세스랑 스레드 차이가 뭐야?"
links: ["[[RAG가 뭐야]]"]
---

# 프로세스와 스레드 차이

## 한 줄 요약
한 줄로 줄인 답.

## 정리
### 핵심
- 모델이 소제목과 목록으로 정리한 본문

## 원문 답변
<details><summary>모델이 처음 답한 원문 보기</summary>

원문 전체 (나중에 근거 확인용)

</details>

## 연결
- [[RAG가 뭐야]]
```

## 왜 이렇게 두었나
- **frontmatter**: 목록·검색·그래프가 파일을 열어 보지 않고도 제목·태그·링크를 알 수 있다.
- **위키링크 `[[제목]]`**: 옵시디언이 링크와 그래프로 인식하는 표기. 노션은 모르므로 내보낼 때 굵은 글씨로 바꾼다 (`server/src/export/notion.ts`).
- **원문 답변 보관**: 요약이 틀렸을 때 원문으로 돌아가 확인할 수 있다.
- 파일 이름은 `YYYY-MM-DD-제목.md`. 같은 날 같은 제목이면 덮어쓴다.
